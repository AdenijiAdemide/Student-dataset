# Fictional Student Dataset

This project contains a fictional dataset created for CUL-CYB 371 – Data Mining and Data Warehousing.

## Dataset fields
- Student ID
- Department
- Level
- Attendance Percentage
- Average Examination Score

## Files
- `create_dataset.py`: Python program that creates the dataset.
- `student_dataset.csv`: Dataset containing 10 fictional student records.

## How to run
1. Install Python 3.
2. Open a terminal in this folder.
3. Run: `python create_dataset.py`

All student records are fictional and are created for educational purposes.
